# Altum, mentoria de liderança com Clênia Oliveira

Landing page da mentoria Altum. Site estático: abra `index.html` no navegador ou publique com o GitHub Pages (Settings › Pages › Branch `main`, pasta `/ (root)`).

- `index.html`: a página, com o cronômetro da oferta (até 12/11/2026, 23h59, horário de Brasília), a sanfona da jornada no celular e as animações.
- `altum.css`: estilos e cores do design system Altum.
- `fonts/`: Century Gothic, Deuterium e Dongra Script.
- `img/`: logo, foto da Clênia e ícones.
